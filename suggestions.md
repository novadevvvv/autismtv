# Suggestions

- Add an explicit interaction mode toggle so Minecraft attack/use is fully suppressed while the panel is focused.
- Forward mouse wheel scrolling to the captured display for browsers, lists, and editors.
- Add clipboard sync controls so copy and paste can move both directions intentionally instead of using temporary clipboard swaps.
- Support drag gestures and click-and-drag for sliders, window movement, and selection in the captured app.
- Add a hotkey to quickly focus and unfocus the panel without needing to click it first.
- Add per-monitor profiles so each display can remember its own resolution, FPS, panel size, and billboard behavior.
- Add audio-device routing options so the captured monitor can optionally mirror or redirect sound.
- Add a low-latency preset that trades image quality for interaction responsiveness.
- Add a higher-refresh preview mode in settings so tuning FPS and focus feels closer to the in-world panel.
- Add a lightweight on-panel cursor overlay so the interaction point is easier to track from a distance.
- Add optional snapping to walls or blocks so the panel can mount cleanly in builds.
- Add a persistent panel entity mode with save/load support per world.
- Add keyboard shortcut passthrough profiles for common desktop actions like Alt+Tab blocking or Ctrl+W confirmation.
- Add diagnostics in the settings screen for active monitor bounds, focus state, capture latency, and dropped frames.
- Add an alternate capture backend later if AWT Robot becomes the bottleneck on some systems.
